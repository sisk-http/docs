# Sisk Framework

> {{ site.Params.description }}

Sisk is an open-source HTTP server framework for .NET written in C#. It is an explicit alternative to ASP.NET for building REST APIs, WebSocket and Server-Sent Events services, JSON-RPC and MCP servers, and static file servers. Install it with `dotnet add package Sisk.HttpServer`.

Every documentation and API page is available as Markdown by replacing `.html` with `.md` in its URL.
